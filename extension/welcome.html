Incognito: Not allowed yet

Chrome’s own “Mute site” setting is not remembered in Incognito. CornMute is — but only if you let it run there.

  1. Click the button below. It opens CornMute’s settings in Chrome.
  2. Scroll down and switch on “Allow in Incognito”.
  3. That’s it. This page will update when it’s on.
You can also do this later from the CornMute popup.

All set. CornMute now works in Incognito windows too.
